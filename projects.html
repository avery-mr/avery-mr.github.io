Learning OpenGL

Building a Real-Time Renderer from the Ground Up

This project explores the fundamentals of real-time graphics programming through OpenGL.

Starting with an empty rendering window, I progressively built the systems needed to display geometry, communicate with the GPU, transform and texture objects, navigate a 3D environment, and implement several forms of real-time lighting.

The goal was not to build a complete rendering engine, but to develop a practical understanding of the graphics pipeline underlying the 3D applications and real-time engines I use professionally.

The Starting Point

From an Empty Window to the First Triangle

My starting point was intentionally simple: create an OpenGL context, open a window, and establish a render loop. At this stage, the application could respond to input, clear the framebuffer, and continuously display the result—but it contained no geometry.

Drawing the first triangle introduced the essential pieces of the GPU rendering pipeline. Vertex data was transferred into a buffer, a vertex array described how that data should be interpreted, vertex and fragment shaders were compiled and linked, and OpenGL was finally instructed to draw the geometry.

Takeaway

The first major lesson: displaying even a single triangle requires a chain of communication between the application, OpenGL, and the GPU.

02

Building the Pipeline

How Does Data Become an Image?

The early experiments became less about drawing individual shapes and more about understanding how information moves through the graphics pipeline.

Geometry begins as data in the C++ application. OpenGL transfers that data to GPU memory and describes how its attributes should be interpreted. The vertex shader processes each vertex, rasterization determines which fragments the geometry covers, and the fragment shader calculates the final output for those fragments.

As I experimented with the pipeline, the information flowing through it became increasingly complex: positions, colors, texture coordinates, uniforms, time, user input, and transformation matrices.

The Rendering Pipeline
C++ Application vertex data / uniforms
GPU Buffers stored in GPU memory
Vertex Shader process each vertex
Rasterization determine covered fragments
Fragment Shader compute final color
Framebuffer image stored for display
Screen displayed to the user
