graphics programming from the beginning.

Weekly notes documenting my progression through OpenGL, C++, GLSL, the graphics pipeline, shaders, transformations, cameras, lighting, and the process of building a technical graphics portfolio.

Week 02

Defining the Project

May 27, 2026

This week I mainly focused on defining the topic and scope of my project. After considering several different possible directions I am leaning toward a curriculum focused on OpenGL fundamentals and shader programming which I feel could help direct my career path towards the more technical side of computer graphics and also give me a deeper understanding of the underlying concepts that power many of the tools I use professionally.

I spent some time setting up my GitHub pages site and experimenting with different themes and layouts. I want the site to serve as both a development journal and a portfolio of work completed throughout CSPB, so in addition to documenting weekly progress, I would eventually like to create dedicated pages for project showcases and links to other GitHub repositories. I am considering building parts of the site directly with HTML and CSS rather than relying entirely on a Jekyll theme but that is certainly not a priority.

I picked up Computer Graphics Programming in OpenGL and spent a little time reviewing other resources like LearnOpenGL and The Book of Shaders. My initial thought was to focus on graphics fundamentals first, understanding the rendering pipeline, transformations, coordinate spaces, and shader basics, and then moving into lighting, materials, and more creative shader development.

One challenge I am finding is that it is rather difficult to build a detailed curriculum and schedule before I have enough familiarity with the material to really judge what can realistically be accomplished within a single semester. I will try to lay out as best as possible a path to a realistic goal, but it may prove to be a bit of a moving target.

Looking ahead to next week, I need to finalize the project scope, establish a rough roadmap, and start working through the introductory OpenGL material. I really want to avoid simply consuming tutorials and actually build small tangible graphics projects as early as possible.

Week 03

Week 4

Setting Up the OpenGL Environment

June 11, 2026

This week I focused on my first milestone in OpenGL: setting up the environment. The heavy lift has been getting the basic project structure in place, setting up CMake and understanding CmakeLists, linking GLFW and GLAD correctly (and learning how they fit into the pipeline) and getting my first C++ program to compile and run. The result was getting a window to open successfully which is not as trivial as expected.

Once the window was running I added a callback to handle resizing, added some very basic keyboard input processing, then experimented with simple rendering loop behavior and was able to change the background color. I spent some time learning more about frame buffer clearing and buffer swapping.

This week felt like clearing a first hurdle. It has been a while since I've done anything with C++ so dusting off the cobwebs a bit. Obviously not doing anything complex for a while but I now feel like I have a working foundation where I can compile code, open a window, initialize some OpenGL functions, and see some results. Next step will be to move from simply clearing the screen to drawing my first vertices and triangles diving into shaders and the actual graphics pipeline. It is surreal working throughout the day on highly complex 3d scene files with hundreds of millions of polys and advanced raytracing and global illumination, and then jumping into this project and getting extremely excited about managing to draw a red triangle.

Week 6

Shaders and the Graphics Pipeline

June 25, 2026

This past week I focused on OpenGL shaders and started digging into how data flows through the graphics pipeline. I learned how vertex data is laid out in memory and how glVertexAttribPointer describes the layout to the vertex shader, dealing with interleaved vertex data, stride offsets and attribute locations. On the shader side I worked with both vertex attributes to pass color information through the vertex shader to the fragment shader, and also worked with uniforms to pass time values into the GPU. I then used sine functions to animate vertex positions, color values and alpha over time. I messed around with different color values to see how the rasterizer smoothly interpolates values between verts.

One of the biggest improvements this week was reorganizing the project structure. I separated shader source into external GLSL files and created a C++ shader class to help with compilation and linking which helped clean up the codebase.

Looking ahead, I’ve decided to skip texturing for now. Even though UV mapping and texturing are obviously important, I feel like my primary goal for the project is understanding the graphics pipeline and I’d rather continue into transformations, coordinate systems, cameras, and lighting. I can track back to textures and UVs after that.

The biggest hurdle right now is that transformations look like a significant jump in complexity. Matrix math and multiple coordinate spaces are considerably more abstract than what I’ve done so far and are pretty daunting so I’m planning on spending extra time making sure I really understand the concepts.

Outside of the graphics work I also need to spend time improving my website. I think I had misunderstood last week’s expectations and though the assignment was to establish the framework for the site and continue to develop it throughout the semester. I haven’t had enough time to finish that yet, so improving the site will be another priority over the next week.

Another challenge I’m still thinking through is how to best document and present my work. So far I’ve been saving screenshots and short MP4 recordings of each step, which I suppose will ultimately become the artifacts for the portfolio. As the project grows I need to figure out how to organize the demos into a sort of narrative that shows the technical progress over time.

Week 7

Mid-Semester Project Update

July 2, 2026

Project Overview

My project focuses on learning the fundamentals of modern computer graphics through OpenGL and C++. Rather than using a game engine such as Unity or Unreal Engine, I wanted to better understand the graphics pipeline by working directly with OpenGL. My original goals were to learn shader programming, become comfortable with the rendering pipeline, and become more comfortable coding and compiling, and building reusable utilities in C++ utilities.

As I have progressed through the first half of the project my goals have shifted only slightly. Instead of moving quickly through tutorials, I have spent more time building a clean, reusable project structure and strengthening my understanding of core concepts before moving on to more advanced topics. I also decided to postpone textures so I could focus on transformations, cameras, and eventually lighting, which are more closely aligned with my long-term interests in graphics programming and technical art.

Accomplishments

So far I have successfully built a modern OpenGL development environment using CMake, GLFW, GLAD, and Visual Studio. I have implemented rendering examples using vertex buffers, vertex arrays, element buffers, multiple shaders, and indexed drawing while gaining a much better understanding of how data flows through the graphics pipeline.

One of the most valuable parts of the project has been learning GLSL shader programming. I have implemented vertex and fragment shaders, worked with vertex attributes and uniforms, and created animated effects driven by time-based calculations and mouse cursor position. I also created a reusable Shader class, and have so far restructured the organization of my C++ project a couple different times into something more maintainable and scalable, with shared utilities and CMake helper functions.

Reflection and Remaining Goals

Overall, I feel that the project is progressing well and remains aligned with my original objectives. I feel like I am developing a much stronger understanding of the graphics pipeline than I did at the beginning of the semester.

During the remainder of the semester, I plan to continue building on this foundation by implementing camera systems, exploring coordinate spaces in more depth, and introducing basic lighting techniques. I also plan to continue improving my portfolio website by organizing project artifacts into polished demonstrations that showcase both the technical implementation and the concepts I have learned.

Week 8

Textures and Transformations

July 9, 2026

This week I ended up bouncing back and forth between textures and shaders and view transformations. I went back and spent some more time on UVs, experimented with blending textures with vertex colors, then blended two textures together in the fragment shader using a mix factor. As a small interactive exercise I hooked up keyboard input so the up and down arrow keys adjust texture opacity in real time.

On the transformations side I implemented model, view and perspective transformations, and everything finally looks like actual 3D instead of squares and triangles on a flat screen. I still need to finish this section by adding movement and camera controls so I can start navigating around the scene.

I continued to spend a fair amount of time cleaning up the project structure. As I collect more and more different shaders for different effects, and as code gets longer and longer I need to make sure everything is organized effectively and start leveraging reusable code and utility classes and assets. I cleaned up the CMake project so adding new demos is much easier.

I like the flow of LearnOpenGL and I've noticed that topics sort of circle back around after learning something new. Pieces are starting to feel like they're falling into place, rather than just a bunch of isolated openGL functions. I really enjoy how each new topic builds on the last, and that I can keep reusing code from previous exercises and just add new functionality instead of starting over every week. It's nice having shaders separated from the application code so I can write and link a completely different pair of vertex and fragment shaders and get an entirely different visual result without having to change much of the C++ code.

Week 9

Three Dimensions

July 16, 2026

This week I finished up the 'basics' of OpenGL. I worked more with transformation matrices and now finally have model, view and perspective transformations working together. I added a moveable camera with keyboard and mouse controls, moved the camera into it's own separate class, and now the scenes and demos are feeling much more interactive and actually 3d instead of just displaying a triangle or square from a fixed viewpoint.

I added a sphere mesh alongside the cube geometry I was already using and started rendering multiple objects in the same scene. I also experimented with randomizing their positions, scale, rotation, and movement. I'd like to start separating out the geometry into their own mesh classes as well so I have reusable primitives I can implement instead of arrays of vertices.

One of the main hurdles was keeping track of which transformations should happen in local space versus world space. Small changes to the order of translation, rotation and scaling can create very different results, and I spend some time debugging objects that weren't displaying as I anticipated. The camera controls also took quite a bit of adjustment getting the mouse input, pitch limits and frame timing to feel right. The math involved with camera angles and perspective transformations is really tough for me to get my head around but luckily most of that is abstracted away and taken care of.

Next up: Lighting and Materials. I want to begin with Phong shaders with ambient, diffuse and specular lighting, then adding surface normals, diving into more complex material properties, and light sources that can move through the scene. From there I should be able to combine the textures, camera controls, xforms, and start putting out some more complex and visually interesting

Week 10

Let Me See That Phong

July 23, 2026

week I focused on setting up basic Phong lighting, which made me a little nostalgic for the days I first started learning 3d modeling 25 years ago. I worked through the ambient, diffuse, and specular lighting components and got a much better understanding of how they each contribute to the final look and how they interact with surface normals and camera position.

I created a scene with a large cube as the primary object and a second smaller cube to represent the light source. The light cube has its own simple shader while the main object uses a separate lighting shader. To make the scene a bit more dynamic I made the light cube orbit the larger cube so I could see how the lighting changed in real time as the light position moved.

I worked with the lighting calculations in both world space and view-space to better understand the differences between the two approaches; neat to compare the math side by side and see that, while the end result is similar, the coordinate system changes how the calculations are performed. I spent some time experimenting with different light colors, object colors, specular strengths, shininess values, and other parameters to get a feel for how they affect the final look. Adding even a very simple lighting setup made the scene so much more visually interesting, and a few material attributes and tuning the lighting parameters makes the plain cube feel much more like a 3d object rather than colored shapes.

Next week I'll dive further into materials, probably look to create a dedicated material class or struct to organize the material properties more cleanly. I also plan to implement multiple light sources and distributions. Outside of the coding work, I also need to start organizing a better presentation of the project for my website, I've accumulated quite a few demos, screenshots, videos and code snippets over the semester and no I need to think about how to present them in a way that clearly shows the progression of the project and the concepts I've learned.

Week 12

Wrapping Up

August 7, 2026

This week I explored more advanced lighting types which I had hoped to finish up last week. We're expanding beyond Phong lighting setups into directional lights, point lights and spotlights. Each type introduced some new concepts, particularly calculating distance-based attenuation for point and spot lights, and using inner and outer cone angles to create a smooth falloff around the edges of a spotlight.

I also started experimenting with combining multiple lights in a scene. I went back and watched some of the first clips I rendered of this project and it is really amazing how much more advanced lighting and shaders and textures profoundly affect the quality of the rendered image. Alongside that I started looking int Assimp for importing more interesting meshes rather than relying entirely on my simple cube or procedurally created geometry.

I've been updating my project website and making sure I have screenshots and recordings that document important milestones along the way. A significant amount of my time this past week has also gone toward finishing my reinforcement learning project. As that project wraps up a I should have more time to return my attention to OpenGL. Although I certainly plan to continue this learning path, there are still several topics I would like to explore briefly before the semester ends. I would like to spend some time investigating a few techniques beyond the basic LearnOpenGL progression so that the final project demonstrates not only what I have learned but also points toward the graphics and shader topics I would like to continue exploring in the future.
